## Claude Code specifics

- For changes that touch several files or an unsettled design, start in plan mode and get the plan approved before editing.
- Use the project skills when they fit: `/grill-me` or `/grill-with-docs` to settle open decisions, `/tdd` for new logic, `/diagnosing-bugs` for defects.
- Before finishing, run the Definition of done checks from `AGENTS.md` and show their output.
- When compacting, keep the list of modified files, the branch name and the commands still to run.
