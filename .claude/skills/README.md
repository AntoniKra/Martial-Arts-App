# Project skills

Skills copied from [mattpocock/skills](https://github.com/mattpocock/skills) at commit `4ae2317` (MIT, see `LICENSE-mattpocock-skills`). Kept unmodified so they can be updated by copying a newer version.

| Skill | Use it for |
| --- | --- |
| `grill-me` / `grilling` | Settling an open plan or decision through rounds of questions with recommended answers |
| `grill-with-docs` | The same, plus recording terms and decisions (`domain-modeling`) |
| `domain-modeling` | Keeping the glossary and ADRs up to date |
| `tdd` | Building logic test-first |
| `codebase-design` | Vocabulary for module interfaces and seams (used by `tdd`) |
| `diagnosing-bugs` | A disciplined loop for hard bugs |

This project keeps its glossary in `combat-training-app/docs/domain-glossary.md` and ADRs in `combat-training-app/docs/adr/`. When a skill mentions `GLOSSARY.md` or `docs/adr/`, use those files.
